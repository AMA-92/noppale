# Instructions pour Créer la Vidéo Démo Noppalé

## 🎥 **Comment réaliser cette vidéo démo**

---

## 📱 **ÉTAPE 1: Préparation**

### **🔧 Outils nécessaires:**
- **OBS Studio** (gratuit) pour capture d'écran
- **Micro USB** ou micro intégré de bonne qualité
- **Navigateur Chrome** avec l'application Noppalé ouverte
- **Compte de test** déjà créé

### **🌐 URL de l'application:**
```
https://noppale-desktop.vercel.app
```

### **👤 Compte de test (si disponible):**
```
Email: demo@noppale.com
Mot de passe: demo123456
```

---

## 📱 **ÉTAPE 2: Configuration OBS Studio**

### **🎬 Paramètres:**
1. **Source** → "Display Capture" (capture d'écran)
2. **Résolution** → 1920x1080 (Full HD)
3. **FPS** → 30 images/seconde
4. **Format** → MP4 (H.264)
5. **Audio** → Activer la capture du micro

### **🔊 Test audio:**
- Parlez dans le micro
- Vérifiez les niveaux sonores (pas trop fort, pas trop faible)
- Testez l'enregistrement de 10 secondes

---

## 📱 **ÉTAPE 3: Enregistrement par scènes**

### **🎯 Scène 1: Introduction (30s)**
```
1. Ouvrir: https://noppale-desktop.vercel.app
2. Zoomer sur le logo Noppalé
3. Faire défiler la page de connexion
4. Voix off: "Bienvenue sur Noppalé..."
```

### **🎯 Scène 2: Inscription (1 min)**
```
1. Cliquer sur "Pas encore de compte ? Créer un compte"
2. Remplir les champs (vitesse normale):
   - Email: demo@test.com
   - Mot de passe: Test123456!
   - Téléphone: +221 77 123 45 67
3. Cliquer sur "Créer un compte"
4. Attendre le message de succès
5. Voix off: "Créez votre compte en quelques clics..."
```

### **🎯 Scène 3: Dashboard (1 min)**
```
1. Laisser le dashboard se charger
2. Zoomer sur chaque carte de statistiques
3. Faire défiler jusqu'au graphique
4. Voix off: "Découvrez votre tableau de bord..."
```

### **🎯 Scène 4: Produits (1m30s)**
```
1. Cliquer sur menu "Produits"
2. Cliquer sur "+ Ajouter un produit"
3. Remplir le formulaire:
   - Nom: "Chemise Traditionnelle"
   - Prix: 15000
   - Stock: 50
   - Catégorie: "Vêtements"
4. Cliquer sur "Enregistrer"
5. Voix off: "Ajoutez vos produits facilement..."
```

### **🎯 Scène 5: Vente (1m30s)**
```
1. Cliquer sur menu "Ventes"
2. Cliquer sur "+ Nouvelle vente"
3. Dans la recherche, taper "Chemise"
4. Sélectionner le produit
5. Mettre quantité: 2
6. Ajouter un autre produit si disponible
7. Remplir client: "Mamadou Diallo"
8. Cliquer sur "Confirmer la vente"
9. Voix off: "Enregistrez vos ventes en temps réel..."
```

### **🎯 Scène 6: Dépenses (1 min)**
```
1. Cliquer sur menu "Dépenses"
2. Cliquer sur "+ Ajouter une dépense"
3. Remplir:
   - Description: "Loyer boutique"
   - Montant: 150000
   - Catégorie: "Loyer"
4. Cliquer sur "Enregistrer"
5. Voix off: "Suivez vos dépenses..."
```

---

## 📱 **ÉTAPE 4: Voix Off**

### **🎤 Script à enregistrer:**
Utilisez le texte du fichier `VIDEODEMO-SCRIPT.md`

### **🔊 Conseils pour la voix:**
- Parlez clairement et pas trop vite
- Utilisez un ton amical et professionnel
- Faites des pauses entre les sections
- Souriez en parlant (ça s'entend!)

### **📝 Enregistrement:**
- Enregistrez chaque scène séparément
- Réécoutez immédiatement après chaque prise
- Refaites les scènes avec des erreurs

---

## 📱 **ÉTAPE 5: Montage**

### **✂️ Logiciels recommandés:**
- **DaVinci Resolve** (gratuit et professionnel)
- **CapCut** (gratuit et simple)
- **Filmora** (payant mais facile)

### **🎬 Étapes du montage:**
1. **Importer** toutes les vidéos capturées
2. **Couper** les début/fin inutiles
3. **Ajouter** la voix off synchronisée
4. **Ajouter** musique de fond (volume faible)
5. **Ajouter** textes explicatifs
6. **Ajouter** transitions fluides
7. **Exporter** en MP4 1080p

---

## 📱 **ÉTAPE 6: Finalisation**

### **🎨 Ajouts graphiques:**
- Logo Noppalé au début et à la fin
- Textes superposés pour les points clés
- Zooms sur les actions importantes
- Curseur animé pour montrer les clics

### **🎵 Musique:**
- Musique libre de droits (YouTube Audio Library)
- Volume: 20% maximum pour ne pas couvrir la voix
- Style: Moderne, africain ou business

### **📱 Export final:**
- Format: MP4
- Résolution: 1920x1080
- Durée: 6-7 minutes
- Taille: < 500MB pour YouTube

---

## 🚀 **Distribution**

### **📺 Plateformes:**
- **YouTube**: Upload avec titre et description optimisés
- **Facebook**: Partager dans les groupes de commerçants
- **WhatsApp**: Envoyer aux clients potentiels
- **Site web**: Intégrer sur la page d'accueil

### **📝 Titres suggérés:**
- "Noppalé: Gérez votre commerce en 5 minutes"
- "Application de gestion pour commerçants africains"
- "Comment gérer sa boutique avec Noppalé"

---

## ⏱️ **Temps total de production**

- **Préparation**: 30 minutes
- **Capture des scènes**: 45 minutes
- **Enregistrement voix**: 30 minutes
- **Montage**: 2-3 heures
- **Total**: 4-5 heures

---

## 🎯 **Résultat final**

Une vidéo professionnelle de 6-7 minutes qui montre:
- ✅ L'inscription facile
- ✅ L'interface moderne
- ✅ La gestion des produits
- ✅ Les ventes rapides
- ✅ Le suivi des dépenses
- ✅ Les rapports intelligents
